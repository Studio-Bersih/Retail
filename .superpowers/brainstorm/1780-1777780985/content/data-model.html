Section 2: Data Model

How transactions, versions, and repair requests are stored

Transaction
id string
currentVersionIndex number
versions Version[]
pendingRequest RepairRequest | null
isDeleted boolean
Version
index number  // 1, 2, 3...
type "original" | "instant" | "approved"
snapshot TransactionData  // full copy
changedFields string[]
createdBy userId
createdAt timestamp
requestId string | null  // if approved PT
RepairRequest (PT only)
id string
transactionId string
status "pending" | "rejected" | "deleted"
proposedSnapshot TransactionData
submittedBy userId
submittedAt timestamp
rejectionReason string | null
revisions number  // resubmit count
