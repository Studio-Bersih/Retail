Item Masuk — User & Admin Flows

Section 3: Creation flow and repair flow

Creating an Item Masuk
User opens Item Masuk page
Clicks + Tambah Item Masuk
Fills form:
▸ Pilih Supplier (dropdown, hardcoded)
▸ Items (SKU + qty + harga beli)
harga beli hidden if config off
▸ Keterangan
▸ Tanggal
Clicks Simpan
✓ Record created (V1)
Stock increases immediately
Perbaikan Transaksi (PT) — same pattern as Item Keluar
USER
Opens Item Masuk history
Clicks Perbaikan Transaksi
Edits any field
Full form — all fields
Clicks Submit Request
⏳ Waiting for admin
Record locked (PT)
✓ Approved
New version
✗ Rejected
Sees reason
Revise & resubmit
or delete request
ADMIN
Sees request in queue
Opens diff view
Original vs Proposed
✓ Approve → stock reconciled
✗ Reject + reason
🗑 Delete request
🗑 Delete record
