Item Masuk — Data Model

Section 2: Entities and relationships

ItemMasuk
id: string
currentVersionIndex: number
versions: ItemMasukVersion[]
pendingRequest: ItemMasukRepairRequest | null
isDeleted: boolean
ItemMasukSnapshot
id: string
outletId: string
createdBy: string
items: Array<{
  productId: string
  qty: number
  hargaBeli: number always stored
}>
totalCost: number sum(qty×hargaBeli)
supplierId: string
keterangan: string
tanggal: string YYYY-MM-DD
ItemMasukVersion
index: number 1, 2, 3…
type: "original" | "approved"
snapshot: ItemMasukSnapshot
changedFields: string[]
createdBy: string
createdAt: string
requestId: string | null
Version timeline:
V1 original → V2 approved → V3 approved
ItemMasukRepairRequest
id: string
itemMasukId: string
status: "pending" | "rejected" | "deleted"
proposedSnapshot: ItemMasukSnapshot
submittedBy: string
submittedAt: string
rejectionReason: string | null
revisions: number
Supplier
id: string
name: string
Hardcoded for now
OutletConfig
outletId: string
showHargaBeli: boolean
Per-outlet · fetched from server
PT Stock Reconciliation (on approval)
qty increased → stock increases further
qty decreased → stock decreases (restore over-count)
product removed → stock decreases by full qty
product added → stock increases by new qty
