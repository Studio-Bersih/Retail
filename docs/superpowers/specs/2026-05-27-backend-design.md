# Backend API Design Spec

**Date:** 2026-05-27
**Project:** Studio Bersih - POS
**Status:** Approved

---

## Goal

Build a Bun + Elysia.js REST API server that replaces all client-side mock data with real endpoints backed by PostgreSQL. The backend lives at `server/` inside the existing monorepo. Every write operation is wrapped in `db.transaction()` — no exceptions.

---

## Tech Stack

| Concern | Choice |
|---------|--------|
| Runtime | Bun (latest) |
| HTTP framework | Elysia.js (latest) |
| ORM | Drizzle ORM + `drizzle-kit` |
| Database | PostgreSQL |
| Cache | Redis via `ioredis` |
| Auth | JWT via `@elysiajs/jwt` |
| Rate limiting | `@elysiajs/rate-limit` |
| Password hashing | `Bun.password` (built-in) |
| Validation | Elysia TypeBox (`t`) at route level |
| Logging | Custom hooks + daily rotating log files |

---

## Naming Conventions

- **camelCase** everywhere — variables, functions, parameters, object keys
- **No single-letter variables** — `item` not `i`, `payment` not `p`, `dbTx` is the minimum for transaction objects (prefer `databaseTransaction`)
- **Descriptive parameters** — `.map(item => ...)` not `.map(i => ...)`, `catch (caughtError)` not `catch (e)`
- Controllers and models mirror each other's domain names exactly (`auth.controller.ts` ↔ `auth.model.ts`)

## Request Lifecycle

Every request flows through the same pipeline:

```
Client Request
  → version.hook    (X-App-Version check → 426 if stale)
  → correlation.hook (attach X-Request-ID)
  → logger.hook     (stamp start time; print/write on completion)
  → auth.hook       (verify JWT Bearer → 401 if invalid; derives session)
  → rateLimiter     (auth endpoints only)
  → idempotency     (POST /transactions, POST /orders only)
  → TypeBox schema  (validate body/query/params → 422 if malformed)
  → controller      (coordinate; call model; shape response)
    → model         (db.transaction() → all writes + audit_log row in one atomic unit)
  → response
```

## Coding Patterns

### Route declaration (routes/index.ts)

```typescript
import Elysia, { t } from 'elysia'
import { login } from '../controllers/auth.controller'
import { authGuard } from '../hooks/auth.hook'
import { idempotencyHook } from '../hooks/idempotency.hook'
import { rateLimiterHook } from '../hooks/rateLimiter.hook'

export const routes = new Elysia({ prefix: '/api' })
    .post('/auth/login', login, {
        use: [rateLimiterHook],
        body: t.Object({
            username: t.String({ minLength: 1 }),
            password: t.String({ minLength: 1 })
        })
    })
    .use(authGuard)
    .get('/items', getItems, {
        query: t.Object({
            outletId: t.Optional(t.String()),
            search:   t.Optional(t.String())
        })
    })
    .post('/transactions', createTransaction, {
        use: [idempotencyHook],
        body: t.Object({ /* see endpoint inventory */ })
    })
```

### Controller pattern

```typescript
// controllers/auth.controller.ts
import type { Context } from 'elysia'
import { findUserByCredentials } from '../models/auth.model'
import { Errors } from '../utils/errors'
import { Messages } from '../utils/messages'

export async function login({ body, jwt, error }: Context) {
    const user = await findUserByCredentials(body.username, body.password)
    if (!user) return error(401, { message: Errors.UNAUTHORIZED })

    const token = await jwt.sign({
        userId:   user.id,
        userName: user.name,
        role:     user.role,
        outletId: user.outletId
    })

    return {
        message: Messages.LOGIN_SUCCESS,
        token,
        user: { userId: user.id, userName: user.name, role: user.role, outletId: user.outletId }
    }
}
```

### Model pattern — read

```typescript
// models/auth.model.ts
import { db } from '../db'
import { users } from '../db/schema'
import { eq } from 'drizzle-orm'

export async function findUserByCredentials(username: string, password: string) {
    return db.transaction(async (databaseTransaction) => {
        const [foundUser] = await databaseTransaction
            .select()
            .from(users)
            .where(eq(users.username, username))

        if (!foundUser || !foundUser.isActive) return null

        const isValidPassword = await Bun.password.verify(password, foundUser.passwordHash)
        return isValidPassword ? foundUser : null
    })
}
```

### Model pattern — write with audit log (highest priority)

```typescript
// models/transactions.model.ts
export async function saveTransaction(payload: NewTransactionPayload, session: JwtSession) {
    return db.transaction(async (databaseTransaction) => {
        const [savedTransaction] = await databaseTransaction
            .insert(transactions)
            .values({
                outletId: session.outletId,
                userId:   session.userId,
                memberId: payload.memberId,
                mode:     payload.mode,
                notes:    payload.notes,
                status:   'completed',
                ...payload.pricing
            })
            .returning()

        await databaseTransaction.insert(transactionItems).values(
            payload.items.map(item => ({ transactionId: savedTransaction.id, ...item }))
        )

        await databaseTransaction.insert(transactionPayments).values(
            payload.paymentMethods.map(payment => ({ transactionId: savedTransaction.id, ...payment }))
        )

        for (const item of payload.items.filter(item => !item.isFree)) {
            await databaseTransaction
                .update(outletStock)
                .set({ stock: sql`stock - ${item.qty}` })
                .where(and(
                    eq(outletStock.itemId, item.id),
                    eq(outletStock.outletId, session.outletId)
                ))
        }

        await databaseTransaction.insert(auditLog).values({
            userId:     session.userId,
            action:     'create',
            entityType: 'transaction',
            entityId:   savedTransaction.id,
            newValue:   payload,
            requestId:  payload.requestId
        })

        return savedTransaction
    })
}
```

### `src/library/utils/requestHeaders.ts` (new)
```typescript
import { APP_VERSION } from './constants'
import { get } from 'svelte/store'
import { auth } from '$library/stores/auth'

export function buildHeaders(extraHeaders: Record<string, string> = {}): HeadersInit {
    const currentSession = get(auth)
    return {
        'Content-Type':  'application/json',
        'X-App-Version': APP_VERSION,
        'X-Request-ID':  crypto.randomUUID(),
        ...(currentSession?.token ? { 'Authorization': `Bearer ${currentSession.token}` } : {}),
        ...extraHeaders
    }
}
```

### `src/library/hooks/usePost.ts` (updated)
```typescript
export async function usePost<ResponseData>(
    endpoint: string,
    body: unknown,
    options: { idempotencyKey?: string } = {}
): Promise<ResponseData> {
    const headers = buildHeaders(
        options.idempotencyKey ? { 'X-Idempotency-Key': options.idempotencyKey } : {}
    )
    const response = await fetch(`${API_BASE_URL}${endpoint}`, {
        method: 'POST',
        headers,
        body: JSON.stringify(body)
    })
    if (!response.ok) throw await response.json()
    return response.json()
}
```

## Resolved Decisions

- **Port:** `3000` in development, `10565` in production. Controlled via `PORT` env var (add to `env.ts` required list).
- **Pagination:** Server-side on all list endpoints. Query params: `page` (1-based, default `1`) + `limit` (default `25`, max `100`). All paginated responses return a consistent envelope:
  ```json
  {
    "data": [],
    "meta": { "page": 1, "limit": 25, "total": 142, "totalPages": 6 }
  }
  ```
  Non-paginated endpoints (outlets, payment-methods, transaction-types, promos) return plain arrays — they are small, cacheable, and fetched once.
- **Factory admin access:** `role: 'admin'` in the JWT payload is sufficient. Admin-only endpoints (`POST /api/coupons`, `PUT /api/coupons/:kode`, etc.) check `session.role === 'admin'` in the controller and return `403` via `Errors.FORBIDDEN` if not.
